# the next ape 🐒

first primates. then sapiens. now the next ape: same monkey head, better tools.

nxape is a small software studio from the jungle. our products are built by a team of AI agents, and a human approves every step.

## 💸 Eximio — family money, no drama
household finance for one person or a whole family: monthly funds, cards, incomes, ARS/USD with daily dollar rates, bank-statement import and reconciliation.

- **a Claude-powered agent in the app.** send it a photo, a PDF statement or a message, and it turns them into transactions you confirm.
- **MCP server** with 13 tools over the data layer, isolated from the app process.
- **own sign-in**: OIDC identity provider with magic links, passkeys and Google.
- `Node` `Express` `SQLite` `Claude API` `MCP` `Fly.io` `Cloudflare` · 180+ test files

→ [nxape.dev/eximio](https://nxape.dev/eximio/)

## 🏭 how we build
every feature runs through a pipeline of specialized Claude Code agents:

product owner → architect → ui designer → developers → testers → merge → production

specialists on call: a DBA with veto power over data, a security reviewer with a blocking verdict, and experts in SEO, content, game feel and infra. quality gates between stages, and a human signs off each one.
